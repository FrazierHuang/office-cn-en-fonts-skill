# Office Chinese-English Fonts Skill

A Codex skill and zero-dependency OOXML cleanup tool for Chinese-English Office documents.

It normalizes Word, Excel, and PowerPoint outputs that mix Chinese and English text: Chinese uses `宋体`/`SimSun`, English uses `Times New Roman`, Chinese-English boundary spaces are removed, and Word/Excel files are kept as black text with unfilled tables.

## Why This Exists

Chinese academic, thesis, report, and submission materials often require different fonts for Chinese and English text. Office files generated by agents or scripts usually miss at least one of these details:

- Chinese text is not `宋体`.
- English text is not `Times New Roman`.
- Word/Excel tables have colored fills.
- Word/Excel text is not black.
- Mixed Chinese-English phrases contain unwanted spaces, such as `河蚬 As` or `As 暴露`.

This repository packages those rules as both a Codex skill and a command-line cleanup/check tool.

## Features

- Enforce Chinese font: `宋体` / `SimSun`.
- Enforce English, numbers, and Western punctuation font: `Times New Roman`.
- Remove spaces between adjacent Chinese and English/numeric text, for example:
  - `河蚬 As` -> `河蚬As`
  - `As 暴露` -> `As暴露`
- Remove those boundary spaces even when Word or PowerPoint splits the phrase across multiple text runs.
- Force black text in Word and Excel.
- Remove table/cell fill colors in Word and Excel.
- Normalize `.docx`, `.xlsx`, and `.pptx` files in place or as new files.
- Check files without modifying them using `--check`.
- Process folders with `--recursive`.
- Create backups before in-place rewrites with `--backup`.
- Run with Python standard library only.

## Install As A Codex Skill

Copy the full folder into your Codex skills directory:

```bash
cp -R office-cn-en-fonts-skill ~/.codex/skills/
```

Then open a new Codex session so the skill can be loaded.

## Command-Line Usage

Fix one or more files and write new `_fontfixed` files:

```bash
python3 scripts/enforce_office_fonts.py file.docx file.xlsx file.pptx
```

Fix files in place:

```bash
python3 scripts/enforce_office_fonts.py --in-place file.docx file.xlsx file.pptx
```

Fix files in place and keep backups:

```bash
python3 scripts/enforce_office_fonts.py --in-place --backup file.docx file.xlsx
```

Check files without modifying them:

```bash
python3 scripts/enforce_office_fonts.py --check file.docx file.xlsx file.pptx
```

Process a whole folder recursively:

```bash
python3 scripts/enforce_office_fonts.py --recursive --in-place ./outputs
```

## Example Output

```text
OK   examples/after/before.docx
OK   examples/after/before.xlsx
OK   examples/after/before.pptx
```

In check mode, files with remaining issues return a non-zero exit code:

```text
FAIL examples/before/before.docx
  - spacing: 1 Chinese-English boundary space(s)
  - word_table_fill: 1 table shading element(s)
```

## Notes

- Excel mixed Chinese-English strings are rewritten as rich text runs so Chinese and English segments can carry different fonts.
- PowerPoint font pairing is enforced, but text color is not forced to black unless you add that requirement separately.
- User instructions should override these defaults when a specific project requires colored text or filled tables.
